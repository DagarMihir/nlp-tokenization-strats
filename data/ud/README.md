# UD Dataset Layout

Store Universal Dependencies corpora by language code:

- `data/ud/en/` for English files
- `data/ud/de/` for German files
- `data/ud/es/` for Spanish files

Recommended naming convention:
- `<lang>_<treebank>-ud-train.conllu`
- `<lang>_<treebank>-ud-dev.conllu`
- `<lang>_<treebank>-ud-test.conllu`

Examples:
- `data/ud/en/en_ewt-ud-train.conllu`
- `data/ud/de/de_hdt-ud-train.conllu`
